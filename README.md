# Distributed System Project Overview  
     
This application is a distributed system designed to coordinate and execute tasks across multiple computing nodes. It simulates a master-worker architecture where a central master server assigns work to several worker nodes, collects intermediate results, and aggregates them. The system also includes client-side simulation to represent user input and data flow. Overall, it demonstrates key concepts of distributed computing, such as task distribution, parallel processing, communication between nodes, and synchronization of results.   
The project consists of 8 classes:

- **MasterServer.java**: Implements the Master Server of the application.  
- **Dummy.java**: Represents the Android application.  
- **Worker.java**: Implements each Worker.  
- **ActionsForApp.java**: The Master thread that communicates with the application.  
- **Chunk.java**: Implements a list of (key, values) where the key is the user’s name and the values are a list of waypoints. It is updated by the workers to store intermediate results.  
- **Client.java**: Maintains the general state/statistics of each user.  
- **Waypoint.java**: Implements a Waypoint object.  
- **Time.java**: Implements a time unit.  

The provided `route1.gpx` file is parsed. To process another GPX file, the file path must be changed in the `Dummy` class. Additionally, the path where the TXT file generated by `Dummy` is saved must be adapted depending on where the code is run.  

The execution order of the classes is: first `MasterServer.java`, then `Dummy.java`, and finally as many instances of `Worker.java` as specified in the arguments.
